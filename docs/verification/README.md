# Verification evidence

The PNG files in this directory are screenshots captured from local or
fixture-backed runs. They are not claims that the public deployment returned
the same values.

The canonical frontend estimate adapter returns:

```text
isAvailable, isMismatch, reason, mismatchReason, series, futureDates,
finalPrice, changePct, direction
```

It does not return the older `isValid`, `price`, or `band` shape. A seven-day
estimate is displayed only when all seven bounds and dates are present and the
forecast ticker, origin date, origin price, and history snapshot agree.

`volatility-serving-audit.json` is a local serving fixture for MSFT. It is
explicitly marked `not_live_verification`; it records the source parquet,
model contract, and corrected horizon values without presenting them as
production evidence.

The accompanying UI captures cover a successful desktop and mobile result,
the keyboard-operable expanded chart, and desktop/mobile partial responses where
the 10-session request fails while the 5- and 20-session results remain
visible. They are generated by `frontend/scripts/capture-ui-verification.mjs`
against deterministic local fixtures; none is a screenshot of the public
deployment.

Example headlines carry `Example fixture` in both title and source. Empty or
failed real news responses are never replaced with these examples.

See [chart-redesign-verification.md](chart-redesign-verification.md) for the
serving investigation, executed checks, limitations, and release status.
